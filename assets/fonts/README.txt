Local website fonts — v09

SpaceGrotesk-Variable.woff2 is the supplied Space Grotesk 2.0 variable font,
weights 300–700. Its license and authors are included. Body text, navigation,
labels and controls use this local file.

Munistic.ttf is the exact supplied Munistic Regular TTF, originally named
Munistic (1).ttf. Munistic.woff is a lossless webfont container made from it.
Its font metadata identifies a regular, static weight-400 face. The local
@font-face declaration uses WOFF first, then the original TTF fallback.
Headings use Munistic; body content stays in Space Grotesk. The supplied font
metadata and copyright are retained in both files.
