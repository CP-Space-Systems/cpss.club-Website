# Measurement data

Copy `template.csv`, name it for an actual test, and add measured numeric rows. The template is header-only and is not a measured dataset.

Connect the file using a dataset option in the project's HTML. See the site-root `GRAPHS.md` for exact instructions. Keep file paths relative to the site root without a leading slash. Do not store private form responses, emails or sign-in-dependent SharePoint assets here.
